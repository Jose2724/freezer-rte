# Freezer RTE

Web app to log RTE carts in the freezers: location (map), temperatures, holds, deliveries,
requests, and the shift log in English (copy to Google Sheets / download for Excel).

This version stores data on each phone (no account needed). Open it in Safari and use
Share > Add to Home Screen. Always open it from the home-screen icon.

Files: index.html (the app), sw.js (offline cache), manifest.webmanifest + icons.
